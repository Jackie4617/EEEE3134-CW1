# EEEE3134 — Personal Webpage Development

This repository contains two versions of my personal webpage developed for EEEE3134 coursework at the University of Nottingham Ningbo China.

The objective is to compare two approaches to AI-assisted web development using OpenAI Codex.

## Published Webpages

**Version 1 — AI-Generated Webpage**

https://jackie4617.github.io/EEEE3134-CW1/version1/

Created using a general prompt, allowing AI to make most of the design and implementation decisions.

**Version 2 — AI-Guided Webpage**

https://jackie4617.github.io/EEEE3134-CW1/version2/

Developed using detailed instructions and iterative refinement, with greater human involvement in design and functionality.

## Technologies Used

HTML5 · CSS3 · JavaScript · OpenAI Codex · GitHub Pages

## Comparison

The two versions are evaluated in terms of visual design, functionality, development experience, and the level of human involvement.
